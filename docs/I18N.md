# Internationalization

The complete current guide is [I18N_GUIDE.md](../I18N_GUIDE.md).

## Quick reference

- Locales: `zh` and `en` in `config/i18n.ts`.
- Route helper: `localized(locale, page)`.
- Layout: `app/[locale]/layout.tsx` sets the HTML language and shell.
- Page title and intro: `content/i18n.ts`.
- Page-specific content: `content/home.ts`, `products.ts`, `research.ts`, `docs.ts`, `playground.ts`, `contact.ts`.
- Language switch: `components/layout/language-switch.tsx`.
- Saved preference key: `thinkcat-language`.
- `/` chooses the saved language, then the browser language, then English. Direct locale URLs take precedence.

## Rules

- Update both locale branches together.
- Chinese uses `在线体验`; the visible word `Playground` must not appear on a Chinese page.
- English visible text must not contain Han characters except the language-switch anchor.
- Keep model IDs, code fields and HTTP methods untranslated.
- Leave unverified links, versions, authors and contact details visibly pending.

## Verification

```sh
npm run build
node scripts/check-export.mjs
node scripts/visual-qa.mjs
```

The export check covers 18 localized pages, language attributes, navigation targets, canonical and hreflang behavior when an origin is set, sitemap and robots.
