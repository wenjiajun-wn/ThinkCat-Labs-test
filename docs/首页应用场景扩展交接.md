- 食品示例明确限定为榛子酱样本。
- 学业示例包含学期表现，目标为 `Dropout / Enrolled / Graduate`。
- 钢材原始标签 `1 / 2 / 3 / 5 / U` 未映射为商业牌号。可见说明明确指出图片牌号不对应示例原始类别。
- 三张图片继续作为概念示意，均有“非实际预测结果”说明；模型及数据来源说明只在模块标题下出现一次。

## 布局与交互

- 四张卡片按电商、软件、食品、教育排序，桌面两列；视口不超过 760px 时单列。
- 桌面内边距 32px、卡片间距 24px；手机分别为 24px、20px，均复用现有变量。
- 没有固定卡片高度。1440px 实测中文卡片约 212px、英文约 239px；同一行自然等高，底部入口对齐。
- 整卡为单一链接，无嵌套按钮或链接；Tab 焦点清晰可见。
- 悬停仅改变底色、边框和箭头的 3px 位移。减弱动态效果时箭头不位移。
- 七个场景和“探索更多示例”均复用 `localized()`；应用区链接关闭预取。加载数据后仍由用户点击运行，没有自动推理。

## 性能与准确率兼容

首页场景配置只有文案、示例 ID 和展示元数据。首页入口 HTML 及其 9 个入口脚本检查未包含示例完整数据哈希或 `queryLabels`；没有通过本轮组件导入 15 份数据或留出集标签。

通过受控响应测试七个场景的中英文推理流程：请求只含 `rows` 和 `target_column`，上下文与待预测划分保持原样，待预测标签仍为 `null`。预测结果回填同一张表，真实标签对应、正确数和准确率计算通过原有评估逻辑验证。没有向请求加入评估标签。
