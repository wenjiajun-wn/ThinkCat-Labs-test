# 信用卡风险示例绑定（2026-11-15）

## 数据核验与任务边界

检查用户提供的 `TabArena-v0.1-45-datasets.zip` 中全部 45 份 Parquet 的名称、目标列和字段。发现尚未接入的 `credit_card_clients_default`（OpenML 46919）。该数据预测客户下个月是否违约，不是逐笔交易欺诈或人工交易复核记录。因此首页对应案例使用「信用卡风险复核 / Credit card risk review」，不将信贷数据冒称交易欺诈数据。

- 原始记录：30,000 行。
- 在线子集：260 行、20 个数值特征、1 个目标列，共 21 列；234 行已标注、26 行留空待预测。
- 目标列：`DefaultOnPaymentNextMonth`，类别为 `No` / `Yes`。
- 省略非数值字段 `SEX`、`EDUCATION`、`MARRIAGE`，没有类别编码、插补或改写数值。
- 沿用既有抽样管线：按类别平衡取原始顺序的完整记录，末尾记录标签留空；子集不代表原始违约率，也不是模型性能评测。
- 原始记录号、源文件 SHA256、抽样规则均保存在数据 JSON。已逐项核对 5,200 个特征值及标签与原始 Parquet 一致。
- 来源：https://www.openml.org/d/46919；原始来源：https://doi.org/10.24432/C55S3H。
- 许可：CC BY 4.0；作者 Yeh、Lien（2009），TabArena 团队整理。完整署名及元数据保留在注册配置与 `46919-source.json`。
