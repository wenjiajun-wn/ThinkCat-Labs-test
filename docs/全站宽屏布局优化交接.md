## 容器规范

普通内容上限 1760px；Playground 工作台上限 1600px。页边距使用 `clamp(20px, 3vw, 56px)`，超出容器上限后居中留白。

保留原有根级 `--container-width`、`--container-gutter`、`--gutter` 与 Hero 专属变量。仅在 `.subpage` 内将既有 `--content-inset` 和 `--gutter` 接到新变量。首页 Developer、应用场景、Header 与 Footer 分别使用明确选择器。没有覆盖首页 Hero 或品牌条。

Docs 的文章容器可以扩展，代码和表格获得更多空间；段落继续使用原有阅读行宽，提示文字也限制行宽。Privacy 正文最大宽度继续为 760px。表单控件、按钮、SVG 原始坐标与宽高比规则保留。

## Hero 冻结验收

- `app/styles/home.css`、`components/visualizations/numerical-field.tsx`、`components/visualizations/terrain-renderer.ts` 的 SHA-256 与修改前完全一致。
- 两种语言、七种视口下，Hero、文字与 Canvas 相关已采集节点的位置、宽高、Padding、字体、行高、颜色、定位和比例没有差异。
- 14 组 Hero 对比截图，13 组逐像素相同；英文 320px 的左上圆角 8×7px 范围内存在 11 个像素差异。正文、主视觉、坐标区域没有像素差异。未将此组报告为逐像素完全相同。
- 对比使用 reduced-motion 静态状态，避免动画时间不同导致假差异。未进行动态帧逐帧同步比较。
- Header 变宽而 Hero 保留现状，因此首页 Header 和 Hero 不再强制共享左右边界，这是本轮明确约束的结果。
