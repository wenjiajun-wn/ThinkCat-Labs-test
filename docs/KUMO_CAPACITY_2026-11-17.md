## 后端最小补丁

`deploy/upgrade-kumo-row-limit.py` 默认只检查；`--apply` 校验已测试源码哈希、编译候选代码、
备份原文件并在原目录原子替换。仅修改总行数上限及对应错误文案。
待预测行数、特征数、类别数、模型参数、接口请求和响应均不变。
不自动重启，重复应用会因源码哈希不同停止。

服务器使用非 systemd 进程管理环境；需要确认 supervisor 的实际配置及服务名称后，
仅重启该 API 服务。不能使用 `systemctl`、`restart all` 或直接假定 PID 永久不变。
上线后应使用同一批测试数据通过 localhost `/predict` 和网站代理分别验证。
