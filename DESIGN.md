# Design research record

The active V5.3 design specification is [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md). This file preserves earlier design research notes.

## Early direction

Numerical Terrain / 数值地形. The site was first organised as a research company website for researchers and technical decision makers, using editorial type and wide procedural data canvases. Runway's public site was read as a narrative reference on 2026-11-08; no assets or code were downloaded.

Early palette: paper `#f5f5ee`, ink `#20251f`, muted `#646a60`, accent `#dcf597`. Typography used local system fonts rather than distributed font files. Layout used a two-column desktop structure and a single mobile column, with a 760px breakpoint. The first stage used native details disclosure, industry buttons, a mobile menu and anchor navigation.

## V4 and V5.1

The numerical field and representation map became the hero subject. Products received matrix, temporal and unified representation studies. V5.1 constrained the H1 to a 48–64px desktop range and a 32–40px mobile range, moved shared type and spacing into CSS variables, and documented bilingual research principles.

## V5.2

V5.2 replaces the visual layer, not the product truth. It introduces the named design tokens, interactive field probe, three distinct product studies, Playground workspace, developer docs, five industry studies and the browser QA pipeline. See [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md), [FRONTEND_ARCHITECTURE.md](FRONTEND_ARCHITECTURE.md) and [V5.2_ACCEPTANCE.md](DEVELOPMENT.md).
